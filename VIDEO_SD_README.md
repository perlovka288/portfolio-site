# Раздел SD: видеоплеер на сайте + шрифты в Cloudinary

Файлы (структура как в репозитории, копировать в корень с заменой, затем commit + push):
- resources.php — видео-карточки открывают плеер в окне (как на видеосайте), а не скачивают файл
- assets/res-video.css — НОВЫЙ файл: стили кнопки Play и окна плеера
- includes/resources_lib.php — videoEmbedInfo() (распознаёт ссылку) + загрузка файлов в Cloudinary
- admin/resources.php, download.php — загрузка в Cloudinary и скачивание из него (из прошлого патча)

Как добавлять видео: раздел SD → «Видео и материалы» → кнопка «+» → название, превью (необязательно),
источник «Ссылка» → вставить ссылку. Добавлять можно сколько угодно видео — каждое станет карточкой.

Какие ссылки открываются в плеере: YouTube (watch / youtu.be / shorts), Vimeo, Rutube,
Google Drive (доступ «всем, у кого есть ссылка»), прямые .mp4/.webm/.mov, видео в Cloudinary.
У YouTube превью подтягивается автоматически. Если ссылка другая — карточка работает как раньше (скачивание/переход).

Существующую карточку «Туториал на Stable Diffusion AMD»: ✏️ Редактировать → «Ссылка» → вставить ссылку на видео → Сохранить.
