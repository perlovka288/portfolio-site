# Несколько файлов у одного материала (шрифты и др.)

Копировать в корень репозитория с заменой, затем commit + push. Новые файлы: assets/res-video.css, assets/res-files.css.
Новая колонка pack_resources.files_json создаётся автоматически при первом заходе (ALTER TABLE ... IF NOT EXISTS).

Как пользоваться (админ):
- «+» в разделе «Шрифты» → источник «Файл» → выбрать сразу несколько файлов (Ctrl/Shift или перетащить) → Добавить.
- Карточка получает кнопку «Скачать (N)»: открывается список файлов, у каждого своя загрузка + «Скачать всё (.zip)».
- Правка (✏️): «Оставить» — как есть; «Добавить» — дописать файлы к имеющимся; «Заменить» — заменить весь набор;
  список «Текущие файлы» — отметь файлы, которые нужно удалить.
- Все файлы идут в Cloudinary (папка kostlim/resources). Если хоть один не загрузился — не сохраняется ничего.

Лимиты: до 45 файлов за раз (max_file_uploads в Dockerfile), до 100 МБ на файл; Cloudinary free — ~10 МБ на файл.
В этот архив также входят видеоплеер для раздела SD и загрузка в Cloudinary из прошлых патчей.
